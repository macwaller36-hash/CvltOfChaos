Quick setup

  • Paste your Client ID
  • Click Open Invite
  • Select your server
  • Authorize with your account

Required server rights

  • Manage Server on your account
  • Bot needs Send Messages
  • Bot needs Read Message History
  • Bot needs Manage Messages for c!send cleanup
